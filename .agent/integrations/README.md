# Integrations

[GitHub](github.md) is the actual source/work-state integration for this repository.
Each integration document must name its authoritative config, external service,
read/mutation effects, tooling, project/organization binding and credential source.
Credentials and tokens never belong in these files. Configuration does not prove
current authentication or authorization. Tool/connector availability grants neither.

No project Mind-Seed, MemPalace, Jira or hosting integration is bound. Add service
references only after configuration is established; do not create speculative stubs.
