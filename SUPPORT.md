# Support

Aetheris UI is not a runnable product yet, so there is currently no installation or runtime support commitment.

## Where To Ask

- Use [GitHub Issues](https://github.com/jikovec/Aetheris-UI/issues) for reproducible bugs, documentation defects, and actionable repository work.
- Use [GitHub Discussions](https://github.com/jikovec/Aetheris-UI/discussions) for design questions, exploratory proposals, and general project questions that are not yet executable work.
- For security-sensitive matters, follow [docs/SECURITY.md](docs/SECURITY.md). Do not put exploit details, secrets, private prompts, or user data into public Issues or Discussions.

Before opening a new Issue, search the existing work ledger to avoid duplicates.

## Scope

Support covers the public repository and, once implemented, the documented Aetheris UI extension behavior. It does not promise support for private local prompts, custom browser modifications, unsupported forks, or undocumented deployment environments.

No response-time, maintenance-duration, commercial-support, or compatibility guarantee is declared.
