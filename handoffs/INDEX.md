## Handoff Rules

Create or update this index when work is intentionally left for a later agent.

Each handoff should include:

- current status
- exact files inspected or changed
- exact blocker or next step
- validation already run
- validation still needed
- links to relevant docs, reports, source areas, tests, or decisions

Do not use handoffs to invent work that has not been requested or justified by repo truth.
