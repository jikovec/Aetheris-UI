# Codex skill compatibility index

Use the native adapters in [`.agents/skills/`](../../.agents/skills/) and the
[canonical toolkit](../../.agent/README.md). The installed Codex scans both locations;
duplicating `SKILL.md` files here creates duplicate selectable names. Keep this index
as the compatibility surface and maintain only one executable Codex adapter per skill.
See [provider discovery](../../.agent/workflows/provider-discovery.md).
